# Portfolio

Personal developer portfolio of Sri Charan Palem, built to showcase projects, skills and open-source work.

## Tech Stack
- React 19 and Vite
- Three.js for 3D visuals
- Framer Motion for animation

## Run locally
```bash
npm install
npm run dev
```
